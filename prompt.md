### Required modules

1. **Student Dashboard:** Profile, journey search, saved journeys and ride requests.
2. **Smart Journey Planner:** Search and display available bus, EV and walking combinations.
3. **Smart Student Pooling:** Match students by nearby locations, destinations and departure times.
4. **Community EV Mobility Network:** EV auto and EV two-wheeler registration, provider availability, nearest-provider matching, ride requests and accept/reject functionality.
5. **Multi-Modal Planner and AI Assistant:** Combine bus, EV and walking journeys; provide travel recommendations using actual application data.
6. **Bus Route Management:** Admin must be able to add, edit and delete buses, create routes, manage stops, assign buses, set schedules, update availability and manage cancellations.
7. **Admin Dashboard:** Manage students, transport providers, vehicles, bus routes, schedules and ride requests.

### Integration requirements
- Use one shared transportation database/data source.
- Admin bus route and schedule updates must immediately reflect in the student journey planner.
- EV provider availability must update in the ride-search results.
- Pooling matches must connect with shared EV ride requests.
- Ensure all forms, buttons, searches and status updates work.
- Use clearly labelled sample data where live integrations are unavailable.
- Respect vehicle capacity and applicable transport rules.

Prioritize functional workflows over decorative UI. Test all modules together, fix errors, and prepare the application for demonstration and deployment.
